Настройки

Для отправки поддерживается Gmail.
  1. Откройте пароли приложений Google и войдите в аккаунт отправителя.
  2. Введите название Booktifier и нажмите «Создать».
  3. Скопируйте пароль из 16 символов, вставьте в поле ниже и сохраните настройки почты.
Для создания пароля нужна двухэтапная аутентификация Google.

Настройки и пароль хранятся только в этом браузере. При отправке пароль передаётся серверу для подключения к Gmail.

Добавьте почту отправителя в список разрешённых адресов Amazon для Kindle.
