# Release Notes

## 1.0.0

- EPUB metadata editor with multiple authors and readable export filenames.
- Seven cover designs, Open Library search, and custom cover uploads.
- English and Russian interfaces with automatic language selection.
- Personal Gmail delivery to Kindle.
- Browser-local email settings and in-memory server processing.
- Docker Compose deployment with automatic HTTPS through Caddy.
- EPUB uploads up to 50 MB and Gmail attachment size checks.
